# FacileTouch - Head Mouse Accessibility Tool

Ứng dụng hỗ trợ công nghệ (Accessibility) giúp người khuyết tật vận động hoặc người mắc hội chứng Parkinson có thể điều khiển chuột máy tính thông qua cử động mặt và ánh mắt.

## Tính năng nổi bật
Facile Touch
1/ Instruction
- Di chuyển: người dùng di chuyển đầu (cụ thể là mũi) để con trỏ chuột trên màn hình di chuyển

- Click = Há mồm

- Cuộn chuột = Há mồm + giữ 2 giây ( lúc đó ngửa lên = cuộn lên, cúi xuống = cuộn xuống )

- Mở bàn phím ảo = nghiêng phải + há mồm 3s

- Tắt bàn phím ảo = nghiêng trái + há mồm 3s

- Gõ phím bàn phím ảo = giữ landmark (mũi) ở bất kì chữ nào trên bàn phím ảo 2 giây(bị động), hoặc há mồm để click(chủ động)

- Phân loại: khi mơi khởi chạy, nghiêng trái = bật chế độ cho người bị run và nghiêng phải = bật chế độ cho người ko bị run

- Pause và resume:
Chủ động: hướng mũi lên góc trái trên cùng màn hình giữ đó 2,7s = pause
Há mồm 3s = resume
Bị động: Ko xuất hiện trên màn hình = pause
Xuất hiện lại = resume

## Yêu cầu hệ thống

- OpenCV, MediaPipe, PyAutoGUI, NumPy
